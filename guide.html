Kurulum rehberi

SMS için 5 dakika, WhatsApp için ilk seferde yaklaşık 20 dakika.

1. Eklentiyi aç

Tabloda Uzantılar › Tellal › Tellal'ı aç. Tablonun ilk satırı başlık olmalı (ör. Ad, Telefon, Sipariş). Telefonlar 0532…, 532… ya da +90 532… biçiminde olabilir; Tellal düzeltir. Panelin üstünden SMS ya da WhatsApp sekmesini seç.

2a. SMS: hesabını bağla

Onaylı bir gönderici adın (başlık) olan bir Netgsm ya da İleti Merkezi hesabı gerekir. SMS ücretini sağlayıcın almaya devam eder.

Netgsm

  1. Netgsm paneline gir, sağ üstten Ayarlar › API İşlemleri'ni aç.
  2. API erişimini aç ve bir API şifresi belirle (ayrı bir alt kullanıcı açman daha güvenli).
  3. IP kısıtı koyma. Tellal Google'ın sunucularından çalışır, onların IP adresi sabit değildir.
  4. Panelde sağlayıcı olarak Netgsm'i seç; kullanıcı adına 850 ile başlayan abone numaranı, şifreye API şifreni yaz, Bağlan.

İleti Merkezi

  1. Panelde Ayarlar › Güvenlik › Erişim İzinleri'nden API erişimine izin ver.
  2. Ayarlar › Güvenlik › API Erişimi'nden key ve hash değerlerini kopyala. Sabit IP ayarını açma.
  3. Türkçe karakterlerin bozulmaması için Ayarlar › SMS › Karakter kodlaması'nda Türkçe desteğini aç.
  4. Panelde İleti Merkezi'ni seç, key ve hash'i yapıştır, Bağlan.

Bağlanınca onaylı başlıkların listelenir. Liste boşsa başlık onayın henüz tamamlanmamıştır.

3a. SMS: mesajı yaz

  1. Gönderici adını seç.
  2. Mesaj türü: sipariş, randevu, ödeme gibi bilgilendirmeler için Bilgilendirme. Kampanya ve indirim duyuruları için Ticari (bireysel ya da tacir); sağlayıcın İYS'de izni olmayan numaralara göndermez.
  3. Metni yaz; + Sütun ekle ile {{Ad}}, {{Sipariş}} gibi alanları ekle. Sayaç karakter ve SMS sayısını gösterir. Türkçe karakter bir SMS'e sığan karakteri 160'tan 155'e düşürür.

2b. WhatsApp: numaranı bağla

WhatsApp Business Platform (Cloud API) hesabı, kalıcı bir erişim anahtarı ve onaylı bir mesaj şablonu gerekir.

  1. developers.facebook.com › Uygulama oluştur › tür: Business › WhatsApp ürününü ekle.
  2. WhatsApp › API Kurulumu: numaranı ekle. Buradaki Telefon numarası ID ve WhatsApp Business hesap ID değerlerini kopyala.
  3. İşletme ayarları › Kullanıcılar › Sistem kullanıcıları › yönetici ekle › Varlık ata: uygulama ve WhatsApp hesabı (tam yetki).
  4. Token oluştur: izinler whatsapp_business_messaging ve whatsapp_business_management, süre: Hiçbir zaman.
  5. WhatsApp Manager'da Ödeme yöntemi ekle; Meta mesaj ücretlerini buradan alır.
  6. Üç değeri panele yapıştır, Bağlan.

3b. WhatsApp: şablon oluştur ve eşle

  1. WhatsApp Manager › Mesaj şablonları › Şablon oluştur.
  2. Kategori: sipariş, randevu, hatırlatma için Yardımcı (Utility); kampanya için Pazarlama (Marketing).
  3. Değişken için {{1}}, {{2}} yaz. Örnek: Merhaba {{1}}, {{2}} numaralı siparişin kargoya verildi. Onay çoğunlukla dakikalar sürer.
  4. Panelde ↻ ile listeyi yenile, şablonu seç, her değişken için bir sütun ya da sabit metin seç.

4. Dene ve gönder

Önizlemeyi kontrol et, Önce kendime deneme gönder ile kendine at, sonra Gönderimi başlat. Sonuçlar Tellal Status sütununa yazılır; gönderilen satırlar bir sonraki seferde atlanır.

Sık görülen hatalar

  • Netgsm kullanıcı adı/şifre hatalı ya da API erişimi kapalı: API İşlemleri'nde erişimin açık ve IP kısıtının kapalı olduğunu kontrol et.
  • Gönderici adı tanımlı değil: Seçtiğin başlık hesabında onaylı değil; ↻ ile listeyi yenile.
  • Türkiye cep numarası değil: SMS yalnızca 05XX ile başlayan Türkiye cep numaralarına gider.
  • Hesaba bağlı İYS markası bulunamadı: Ticari gönderim için sağlayıcında İYS marka kodunu tanımla ya da mesaj türünü Bilgilendirme yap.
  • WhatsApp şablonu bu dilde yok: Şablonun dili (ör. tr) ile seçilen aynı olmalı; listeyi yenile.
  • WhatsApp erişim anahtarı geçersiz: Bağlantıyı kaldırıp yeni token ile yeniden bağlan.

Setup guide

About 5 minutes for SMS, about 20 minutes the first time for WhatsApp.

1. Open the add-on

In your sheet choose Extensions › Tellal › Open Tellal. Row 1 must hold column names (for example Name, Phone, Order). Pick the SMS or WhatsApp tab at the top of the sidebar.

2a. SMS: connect your account

You need a Netgsm or İleti Merkezi account with an approved sender name. Your provider keeps billing SMS as before. SMS goes to Turkish mobile numbers.

  1. Netgsm: in the panel open Settings › API, turn on API access and set an API password. Don't set an IP restriction: Tellal runs on Google's servers, whose IPs change. Enter your subscriber number (starts with 850) and the API password.
  2. İleti Merkezi: allow API access under Settings › Security, copy the key and hash from API Access, and turn on Turkish character encoding under Settings › SMS. Don't enable static IP.

3a. SMS: write the message

Pick the sender name and the message type (informational, or commercial for individuals or merchants, which your provider checks against İYS). Write the text and use + Insert column to add fields like {{Name}}. The counter shows characters and SMS parts.

2b. WhatsApp: connect your number

  1. developers.facebook.com › Create app › type Business › add WhatsApp.
  2. WhatsApp › API Setup: add your number and copy the Phone number ID and WhatsApp Business Account ID.
  3. Business settings › Users › System users › add an admin › assign the app and the WhatsApp account with full control.
  4. Generate token with whatsapp_business_messaging and whatsapp_business_management, expiry Never.
  5. Add a payment method in WhatsApp Manager; Meta bills message fees there.
  6. Paste the three values into the sidebar and click Connect.

3b. WhatsApp: create and map a template

  1. WhatsApp Manager › Message templates › Create template. Use Utility for orders, bookings and reminders; Marketing for promotions.
  2. Add variables with {{1}}, {{2}}. Approval usually takes minutes.
  3. Refresh the list in the sidebar with ↻, pick the template and a column or fixed text for each variable.

4. Test and send

Check the preview, use Send a test to myself first, then Start sending. Results go into the Tellal Status column, and sent rows are skipped next time.
